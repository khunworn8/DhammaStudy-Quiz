วิธีนำไฟล์ขึ้น GitHub Pages หรือ Vercel (ฟรี 100%)

แอปนี้เป็นไฟล์เดี่ยวสมบูรณ์ (index.html) ที่มีข้อสอบครบ ๓๐๘ ข้อในตัว ไม่ต้องใช้ฐานข้อมูลหรือเซิร์ฟเวอร์หลังบ้าน สามารถอัปโหลดขึ้นได้ฟรีตลอดชีพ:

วิธีที่ ๑: GitHub Pages (ฟรีไม่จำกัด ไม่ใช้ Credit)

1. สมัครหรือล็อกอินที่ github.com แล้วกด New Repository ตั้งชื่อเช่น dhamma-quiz (เลือก Public)
2. กด uploading an existing file แล้วลากไฟล์ index.html นี้วางลงไป กด Commit changes
3. ไปที่แท็บ Settings → Pages ตรงหัวข้อ Branch เลือก main แล้วกด Save รอ ๑ นาทีจะได้ลิงก์สาธารณะส่งให้เพื่อนทันที

วิธีที่ ๒: Vercel (อัปโหลดง่ายและเร็วมาก)

1. เข้าเว็บ vercel.com (ล็อกอินด้วย GitHub หรืออีเมล)
2. กด Add New → Project เลือก Repository dhamma-quiz จาก GitHub แล้วกด Deploy
3. ได้ลิงก์ https://dhamma-quiz-xxx.vercel.app พร้อมใช้งานบนมือถือและคอมพิวเตอร์ทันที
